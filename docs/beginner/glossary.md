# Glossary

Train set: Data used to fit the model.

Validation set: Data used to choose thresholds and settings.

Test set: Data reserved for final reporting.

MCC: Matthews Correlation Coefficient, a balanced score for binary classification.

AUPRC: Area under the precision-recall curve, useful for imbalanced data.

Checkpoint: Saved model weights.

Manifest: A JSON record of files, settings, seeds, software, and provenance.

GenBank: A sequence format that can include feature annotations.

SBOL: Synthetic Biology Open Language, a standard for biological designs.

FASTA: A sequence-only text format. It does not contain supervised labels by itself.

Computational prediction: A model-generated annotation, not experimental confirmation.
