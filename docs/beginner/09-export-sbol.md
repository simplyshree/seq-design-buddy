# Export SBOL

Purpose: Create interoperable design artifacts.

Prerequisites: Annotation outputs or a design artifact.

Steps:

1. Generate SBOL export.
2. Validate the export.
3. Read errors and warnings.
4. Regenerate when possible.
5. Download only validated SBOL for Canvas.

Expected output: SBOL3 file and validation report.

Common errors: Invalid roles, missing sequence locations, or unvalidated export.

Verify success: The validation report is attached to the SBOL artifact.

Next step: Open Canvas.
