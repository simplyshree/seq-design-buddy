# Overview

Purpose: Learn the full SeqTrainer Workspace path from upload to reproduction.

Prerequisites: A sequence file or a labeled dataset, plus a project goal.

Steps:

1. Upload a supported file.
2. Validate biological design formats.
3. Inspect sequence and label readiness.
4. Configure a fair benchmark or annotation plan.
5. Run locally only for lightweight checks, or use Colab/HPC handoffs.
6. Compare metrics without tuning on test data.
7. Annotate, export, visualize, and reproduce.

Expected output: A tracked project with artifacts, checksums, warnings, and next steps.

Common errors: Missing labels, invalid SBOL, unsupported file extension, or skipped heavy model dependencies.

Verify success: Each step shows an output artifact or an explicit skipped/unavailable state.

Next step: Upload data.
