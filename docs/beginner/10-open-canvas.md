# Open Canvas

Purpose: Visualize or edit the validated SBOL file in SBOL Canvas.

Prerequisites: A downloaded, validated SBOL file.

Steps:

1. Download the SBOL file.
2. Open SBOL Canvas in a new tab.
3. Use the Canvas import/upload flow.
4. Inspect glyph assignments.
5. Return to the workspace when finished.

Expected output: A Canvas handoff record.

Common errors: Trying to iframe Canvas or assuming a direct upload API that has not been documented.

Verify success: Canvas opens separately and the workspace project remains intact.
